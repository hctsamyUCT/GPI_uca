Organisation des fichiers

  • ✓ config/ : Contient la configuration de la base de données
  • ✓ includes/ : Contient les fonctions et classes utilitaires du système
  • ✓ pages/ : Contient les différentes pages de l'application organisées par rôle
  • ✓ assets/ : Contient les ressources CSS pour l'interface utilisateur
  • ✓ index.php : Point d'entrée principal de l'application

Architecture logicielle

📂
Organisation modulaire : Structure par dossiers fonctionnels (admin, user, common, archives)
🔄
Séparation des responsabilités : Fonctions utilitaires dans includes/, pages dans pages/
🔒
Authentification par rôles : Séparation des interfaces admin/user avec contrôle d'accès
🔧
Outils spécialisés : Fonctionnalités d'export, gestion de tickets et statistiques
